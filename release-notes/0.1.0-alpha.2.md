# Rizal Maulana 0.1.0-alpha.2

Mengembalikan enam label kecil sesuai desain: STRUCTURAL ENGINEER, RIZAL MAULANA ENGINEERING, KARYA PILIHAN, SPIRIT KERJA, RAGAM LAYANAN dan KARYA LAINNYA. Gaya Roboto Light kapital dalam outline pill mengikuti PDF pengguna. Tidak mengubah isi, media, homepage, menu atau status publikasi.

Template menyediakan fallback label untuk instalasi alpha.1, sehingga label tampil setelah update kode tanpa harus Apply ulang blueprint. Blueprint menambahkan enam field opsional untuk pengeditan label; Review/Apply struktur secara terpisah diperlukan jika ingin mengedit field baru di WordPress. Nilai existing tetap dipertahankan. Karya Pilihan tetap hanya muncul ketika ada Proyek Rizal published yang dipilih pada slot Beranda; tanpa proyek terpilih, seksi dan label tersebut tetap disembunyikan.

FP alpha.22+, FT alpha.7+, WordPress 6.7+, PHP 8.3+. Rilis alpha.1 tidak ditimpa. Source ini belum dipush oleh Codex.
