# Rizal Maulana 0.1.0-alpha.1

Paket awal child theme Falcon untuk review lokal/staging. Beranda delapan bagian mengikuti PDF pengguna, dengan menu gulung, hero berkabut putih, profil sticky, count-up, lima slot karya, Spirit Kerja mengikuti scroll, layanan sticky, pengetahuan, kolaborasi dan footer yang menutup gambar.

Template maintenance disalin dari trialrizal alpha.5 dengan key rm_* tetap, kemudian komposisi, dekorasi dan motion dikembalikan sesuai standalone index.html pengguna. Ditambahkan field email maintenance; font Roboto normal/italic 100–900 tersedia lokal. Header mengikuti scroll, identitas RIZAL MAULANA memakai Roboto Light, panel menu putih dengan teks hitam dan tombol hitam. Tidak mengimpor data trialrizal, media, menu, homepage atau status publish. Blueprint memetakan enam Page utama dan maintenance melalui review manusia. Seluruh copy perlu review sebelum peluncuran; statistik default tersembunyi dan proyek wajib dipilih dari konten published. Gambar bundled adalah referensi sementara dari pengguna, bukan bukti karya atau foto terverifikasi.

Membutuhkan Falcon Theme alpha.7+, Falcon Plugin alpha.22+, WordPress 6.7+, PHP 8.3+. Bukan rilis stable. Paket awal lokal dengan source belum committed tidak memenuhi provenance distribusi remote; build release ulang dari commit bersih melalui workflow.
